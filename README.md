# cw-final

Multi-module Java client-server application built with Apache Maven (`gr.uop:cw-final`, `v0.0.1`).[cite: 2]

## Repository Structure

- `pom.xml` — Root Maven POM aggregating the `Server` and `Client` modules.[cite: 2]
- `Server/` — Server module.[cite: 2]
- `Client/` — Client module.[cite: 2]
- `.gitignore` — Ignores Java, Maven, Eclipse, and VS Code build/IDE files.[cite: 1]

## Getting Started

### Prerequisites
- Java (JDK)
- Apache Maven

### Build
```bash
mvn clean package
